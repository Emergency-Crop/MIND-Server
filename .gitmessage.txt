#   <타입> 리스트
INIT     : 프로젝트 시작, 초기 설정
CONFIG   : 구성(설정) 파일 추가 및 갱신
DEPS     : 외부 패키지 의존성 갱신
FEAT     : 신규 피처(기능/비기능 모두 해당) 추가
REFACTOR : 코드 리팩토링 (로직 변경 없이 구조, 포맷 정리 등)
FIX      : 버그 수정
HOTFIX   : 특정 이슈로 인해 긴급하게 임시 수정
CHORE    : 기타 모든 수정 사항 발생 시 사용
REVERT   : 코드 복원, 변경 사항 되돌리기
RENAME   : 파일, 디렉토리 이동 또는 이름 변경
REMOVE   : 파일 및 디렉토리 삭제
DB       : 데이터베이스 관련 작업 (스키마 변경, 연동 등)
TEST     : 테스트 코드 추가 또는 수정
MERGE    : 브랜치 병합
CI       : CI 빌드 수정
DEPLOY   : 배포 및 관련 설정
LOG      : 로그 추가, 수정 또는 제거
COMM     : 주석 추가, 수정 또는 제거
DOCS     : README 등 문서 수정

#   Fixes        : 이슈 수정중 (아직 해결되지 않은 경우)
#   Resolves     : 이슈 해결했을 때 사용
#   Ref          : 참고할 이슈가 있을 때 사용
#   Related to   : 해당 커밋에 관련된 이슈번호 (아직 해결되지 않은 경우)
#   ex) Fixes: #47 Related to: #32, #21
